## Actions

Actions taken through the AI assistant are saved, with their outcomes, on the **Actions** page (/assistant/actions). When the assistant shows **View actions** beside an action that is still in progress, select it to open that page.

## Agent Reviews

Agent Reviews is part of **Agent Quality**, which is shown to platform and partner administrators only. A customer account does not see it. Where it is shown, it is used to review conversations for quality.

1. Select **Agent Reviews**.
2. Open a conversation.
3. Review the transcript and any recording.
4. Record your assessment where the controls are available.

Use Agent Reviews to build a consistent view of agent quality across a campaign rather than judging single calls in isolation.

## Notifications

Talk-Lee can notify you about events that need attention, such as a campaign problem or a usage threshold.

Notifications include new qualified leads, failed calls and low remaining minutes. To choose which kinds of notification show a pop-up, and their priority, use **Notification Preferences** on the **Settings** page.

1. Select the notification control in the top bar.
2. Review unread items.
3. Open an item to go to the relevant area.
4. Mark items as read once handled.
