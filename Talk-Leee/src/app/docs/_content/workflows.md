For a new outbound campaign:

1. Prepare the campaign objective.
2. Prepare the knowledge base.
3. Create the campaign.
4. Define the agent role and first useful outcome.
5. Enable only required next actions.
6. Configure required lead fields.
7. Add campaign guidance.
8. Set the calling hours.
9. Select and preview the voice.
10. Confirm the telephone route is ready.
11. Upload contacts.
12. Test the AI agent.
13. Test interruption, objections, email capture, and actions.
14. Launch the campaign.
15. Monitor the Dashboard and Analytics.
16. Review Call History and recordings.
17. Clear follow-ups in Assistant.
18. Improve guidance/knowledge based on real calls.

For a new inbound agent:

1. Define the role and inbound objective.
2. Prepare the knowledge base.
3. Configure the greeting and approved actions.
4. Select the voice.
5. Connect the phone/SIP route.
6. Test common and difficult scenarios.
7. Route production calls only after the test flow passes.
8. Monitor call history, recordings, and analytics.
