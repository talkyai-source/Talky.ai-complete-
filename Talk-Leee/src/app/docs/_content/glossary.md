| Term | Meaning |
| --- | --- |
| **AI minutes** | Talk-Lee platform minutes consumed by AI conversation. Included in your plan allowance. |
| **Barge-in** | The caller interrupting the agent while it is speaking, and the agent stopping to listen. |
| **CDR** | Call detail record. The technical record of a call — numbers, times, duration, outcome. |
| **Concurrent calls** | How many calls your account can run at the same time. Set by your plan. |
| **DNC / opt-out** | Do not call. A person who has asked not to be contacted again. |
| **Lead** | A contact whose call met the campaign's qualification criteria. |
| **LLM** | Large language model. The model that decides what the agent says. |
| **MFA** | Multi-factor authentication. A second step at sign-in, in addition to your password. |
| **Overage** | Usage beyond your included allowance. |
| **Passkey** | A sign-in method using your device's own unlock, instead of a password. |
| **PBX** | A telephone system. Talk-Lee can connect to one to place and receive calls. |
| **PSTN** | The public telephone network. Calls to ordinary phone numbers. |
| **Recovery code** | A single-use code that lets you sign in if you lose your MFA device. |
| **SIP** | The protocol used to carry calls between Talk-Lee and your telephone provider. |
| **STT** | Speech to text. Converting what the caller says into words. |
| **Tenant** | One customer account within Talk-Lee. Partners manage several. |
| **Trunk** | A configured connection to a telephone provider, used to place and receive calls. |
| **TTS** | Text to speech. Converting the agent's words into the voice you hear. |
| **Turn-taking** | How the agent decides when the caller has finished speaking and it is its turn. |
| **Webhook** | An address Talk-Lee can send event notifications to, so your own systems can react. |
