# Contact test-contract migration — 2026-10-07

The revised live contact path deliberately removed scripted readback/parser helpers. Six historical test modules still imported or replayed those helpers, causing collection failure and testing an obsolete workflow. This is a tests-only follow-up to prompt source `0c385e86` and contact sources `f9a725cc` / `4dd3c252`.

The original bounded collection attempt collected87 cases and failed importing `_agent_read_back_email` in the phantom-goodbye module. The migration retires35 named test functions that prescribed removed readback/interstitial gates, exact spoken prompts, provider-first/line-number scripts, parser replay or the deleted speech judge. The [exact retired list](artifacts/contact-test-contract-migration/retired-assertions.json) records every name; none is hidden behind skips/xfails and no deleted app helper was restored.

Retained coverage includes the historical pure email/phone/normalizer utilities (explicitly labeled diagnostic), known-line lookup, saved contact outcomes and unresolved follow-up notes, suppressed-hangup retry/history preservation, retry-instruction cleanup on success/failure, and transport utility behavior. Neutral prompt assertions now check actual value/status without commanding an exact sentence. The full suppressed-turn test verifies speech/history preservation without automatically arming the retired parser workflow.

Three current-boundary cases replace unique original-call replay concerns using the existing model-contact fixture: the recorded “Remove the dot” correction stays pending until a later model confirmation; a second email and a second phone are confirmed/persisted beside the first. These use actual `record_contact` and canonical save logic with synthetic SQL ports. They do not prove that a real model interprets the original audio correctly.

The first post-migration run had78 passes/two assertion failures: old parser attempts produce `needs_clarification`, which the neutral context correctly preserved. Final seven-module check: **114 passed,46warnings,3.35s**, including80 cases across the six changed modules and34 existing model-contact controls. RuffF passes. Diff check passes after an EOF-only whitespace correction; no behavior changed after the final run. The counts overlap and are not separate acceptance totals.

No provider, actual database, browser or audio was exercised. The fixture uses the existing backend virtualenv, not a fresh dependency environment. Source files and commands are recorded in [checks.json](artifacts/contact-test-contract-migration/checks.json); [collection failure](artifacts/contact-test-contract-migration/collection-before.txt) and [final test log](artifacts/contact-test-contract-migration/affected-final.txt) are preserved.
