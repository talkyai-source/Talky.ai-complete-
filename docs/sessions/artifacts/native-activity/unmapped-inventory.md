This inventory changes no matrix, fixture, prompt, policy or coverage count. Existing test references identify reusable boundaries, not new executions or current live passes. Source comments describing older calls are historical context, not measurements from this investigation.

The common native runner injects declared provider events and synthetic media receipts (`tests/qualification/ag04_native.py:212`); the traditional runner supplies synthetic SDK output. Neither performs the audio-to-recognition experiment required by the first three conditions. A meaningful local silence or text-echo replay would therefore add explicitly limited runtime-boundary evidence, not a human/acoustic pass or profile approval.

The concrete defect found during this inventory was native activity bookkeeping: actual accepted new caller finals did not refresh the real `CallSession.last_activity_at`, although the common telephony watchdog uses it for inactivity. The separate [verification](verification.md) records the bounded repair and its synthetic proof. All seven matrix IDs remain unchanged and unmapped; the preserved Groq semantic failure and all acceptance thresholds remain unchanged.
