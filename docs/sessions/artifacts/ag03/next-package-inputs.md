The current code retries transient capture/revocation failures on a later turn, and intentionally memoizes permanent validation rejection. Test the actual supported paths instead of equating a caught exception with successful saving.

This is an AG05 hypothesis to verify with real saved states, not a demonstrated AG03 persistence result.
