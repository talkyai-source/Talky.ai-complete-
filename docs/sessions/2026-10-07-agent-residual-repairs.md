## Defects and resulting behavior

| Symptom | Root cause | Repair |
|---|---|---|
| A caller's short “Yes” disappeared while the agent was idle, unless its previous line ended with a question mark. | Backchannel suppression ran without requiring active agent speech. | Suppression now requires active TTS. An idle caller's final short answer reaches the model. Actual speech-overlap handling remains. |
| A confident first answer such as “42” was rejected. | The first-turn content check required letters. | Decimal digits count as meaningful input; confidence and punctuation-only checks remain. |
| The call could close during a fresh partial “Okay…”. | The courtesy/goodbye exemption ran before checking whether the caller was still speaking. | A fresh speaking floor vetoes closing first. A stale flag expires, and quiet, legitimate closing remains possible. |
| After saving a second email or phone, the model could no longer correct, confirm or withdraw the first. | Tool operations, prompt facts and persistence acknowledgements selected only the current entry; earlier entries were assumed confirmed. | The existing tool accepts an optional stable `field_key`. Earlier entries retain their positions and truthful status. Save success must match the selected entry's acknowledged value/status; another contact's success cannot satisfy it. Omitted/null keys retain current-entry behavior and current action recipients remain unchanged. |
| The agent lost an earlier correction after a long but otherwise ordinary conversation. | Traditional requests silently retained only 40 messages, regardless of available model context. | The request retains verbatim history while it fits the configured model's estimated context budget. Necessary omissions remove whole oldest exchanges, preserve current runtime facts and caller quotes, and tell the model that older details are unavailable. Canonical stored history is unchanged. |
| A long knowledge heading blocked catalog browsing, or the model exhausted three rounds before reading the selected source. | Navigation labels shared the page bound with full authored headings; each page used an ordinary tool decision. | Navigation labels are explicitly shortened, while authored source remains complete. Unfit metadata entries return an advancing, explicit skip. Verified advancing catalog pages can receive up to four extra navigation rounds. The live traditional streamer is wired to this budget, including Gemini's separate loop. |
