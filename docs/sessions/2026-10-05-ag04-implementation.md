## Root causes and repairs

1. **An opt-out with a continued question ended the call immediately.** Traditional TurnEnder treated every DNC disposition as permission to hang up. It now retains and attempts the existing durable opt-out path while allowing the continued question. The existing shared caller-end policy controls closure. Failed persistence retains the retry flag; quoted, historical and negated opt-outs do not acquire caller authority. This offline replay intercepts the persistence port and does not prove durable DNC; native teardown persistence and worker-death timing remain operational acceptance work.
2. **An unsupported price could bypass grounding when expressed as `GBP 999`.** The existing amount/currency guard handled symbols and currency words but missed ISO codes. Six bounded existing currencies now use the same amount, period, unit and tax matching. An explicit currency code is never corrected to a different currency. Product identifiers and irrelevant or rejected source material remain negative controls. This is not a universal financial-claim detector.
3. **Interrupted-opening state was rejected by the real provider serializer.** Guidance appended after the closing live-state marker violated that serializer's envelope contract. The existing interruption instructions remain; a compact `opening=interrupted` fact now stays inside the marked block. The largest tested valid unknown-state combination is 767 characters against the unchanged 768 limit. The initial populated-known fixture was smaller, so the final tests explicitly cover both.
4. **A clear email correction could retain the old address.** `Correction, my email is…` and `Actually, my email is…` missed the anchored self-email cue. The narrow prefix repair recognizes those direct statements while preserving quotation, third-party, negation, syntax and confirmation checks. The replacement is unconfirmed. Phone correction already worked in the bounded probe and did not receive a speculative parser change. Revision-aware durable contact handling remains AG05 work.
5. **A spoken clarification was absent from conversation history.** The first-turn low-confidence branch submitted the fixed clarification and returned before recording it. Successful uninterrupted submission now appends that assistant text to history without promoting rejected recognition to caller evidence. Interrupted, disconnected and failed submission are not called heard or completed. Canonical durable transcript handling remains AG05 work.
6. **The direct-provider smoke utility listened for obsolete events.** It now consumes complete `response_candidate` output and waits past a tool-only response for spoken continuation. Its description and result distinguish provider generation from application guards, playback and human hearing. Only fully fake tests were run; the utility itself can make paid calls and was not invoked against a provider.

No governed prompt template, model default, sampling default, provider roster or native/traditional architecture was replaced. The changes follow reproduced boundary failures rather than adding topic-specific prompt rules.
