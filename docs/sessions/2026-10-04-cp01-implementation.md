## Implemented behavior

- The form calls one dedicated anonymous Next endpoint, which forwards only validated bounded data to the configured backend. It neither forwards login credentials nor triggers authentication refresh.
- The backend commits a platform-owned `public_contact_enquiries` row before returning an acceptance receipt. The browser request reference, database primary ID and receipt ID are the same UUID. A database conflict plus canonical payload hash makes concurrent/repeated submission return the original receipt; changed content under the same reference cannot overwrite it.
- A failure or unverified response retains the frozen pending request for safe retry. Double-clicks are synchronously blocked. Same-tab reload recovery uses session storage with a 24-hour restore limit checked on loading, not an idle-tab purge. Storage denial, clearing, another tab or session loss cannot guarantee browser recovery; the UI states the relevant limitation. An expired unresolved submission retains its opaque reference rather than silently becoming a new request.
- Confirmation means intake acceptance. It does not claim that an email was sent, delivered, read, or acted on. The existing email link remains; placeholder telephone/address/hours were removed.
- Admin has a platform-only Website Enquiries page with New/Handled/All filtering, bounded pagination, refresh, safe text rendering and server-confirmed handled/reopen actions. Enquiry requests have a 15-second timeout. A failed or timed-out update does not create a success state; staff can refresh to reconcile it.
- Backend access checks protect both list and status changes. Forced row-level security denies ordinary tenant database access. The public response contains receipt metadata only. No public retrieval endpoint or CRM/ticket subsystem was introduced.
- Previously identified unsupported public claims and two claim-bearing healthcare image renderings were removed or replaced with bounded capability descriptions. See the [claim inventory](2026-10-04-cp01-public-claims.md). Image assets were retained.
